# myUNC Scraper
Quick tools for UNC's web portal, such as:
- Export schedule as ICS
- Check for changes in Grades
    - Notifies through ntfy
    
# How to use
## Setup
```bash
uv sync
```
## Running
- For CLI
```bash
uv run main.py
```
- For args, see help for info
```bash
uv run main.py -h
```
